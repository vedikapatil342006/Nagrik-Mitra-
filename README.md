Assisting Citizens in Using Government Digital Portals

Nagrik Sahayak is a web-based Community Engagement Project designed to help citizens easily discover and use government schemes and digital services. The platform provides simple information, eligibility guidance, required documents, step-by-step application instructions, official portal links, and application tracking support.

Key Features

- 🔍 Search and explore government schemes and services
- 🎯 Find schemes based on user eligibility
- 🏛️ Access information about government digital portals
- 📋 Step-by-step guidance for online applications
- 📄 Required document checklists
- 🔗 Direct links to official government portals
- 📊 Application tracking and user dashboard
- ⚖️ Compare government schemes
- 🌐 Multilingual support — English, Hindi and Marathi
- ❓ FAQ and digital assistance for common problems

Objective: To reduce the difficulty citizens face while accessing government digital services by providing clear, accessible, and easy-to-follow guidance in one platform.

Technology: HTML, CSS, JavaScript
